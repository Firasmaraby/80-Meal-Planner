# Eighty

A micronutrient-first meal plan app. Users pick a plan for their calorie band and cuisine, follow it, and watch every vitamin and mineral fill in. A nutrient counts as done at **80% of the RDA**, the framework's finish line.

Built with Expo (React Native) for iOS and Android, plus a web preview. Supabase is the backend, and the app works fully offline without it.

## What's inside

| Area | Where |
|---|---|
| Screens (Expo Router) | `src/app/` (tabs: Today, Board, Plans, Meals, You; plus meal library detail, meal swap, food search/detail, nutrient sheet, Learn, onboarding, grocery, admin upload) |
| Nutrition engine (pure TS, tested) | `src/engine/`: DRI tables, totals, the 80% board, pillars (sat fat, omega 6:3, glycemic load), swaps, gap closer, search |
| Design system | `src/ui/`: tokens, primitives, Ring / NutrientTile / MacroBar, meal cards, panels |
| State | `src/state/`: persisted store (zustand + AsyncStorage), day projections, catalog |
| Education copy | `src/content/tips.ts` |
| Food DB + plans (bundled) | `src/data/` (generated by `pipeline/`; the current files are a **sample** set) |
| Excel plan template + importer | `templates/`, `src/import/` |
| Backend | `supabase/` (schema, RLS, RPCs), `src/lib/` (client, sync, plans repo) |
| Food DB cleanup pipeline | `pipeline/` (Python) |

## Run it

```bash
npm install
npm test                 # engine, importer, sync tests
npx tsc --noEmit         # typecheck
npx expo start           # press i / a for simulators, w for web
```

Native modules (haptics, SVG) work in Expo Go. Store builds use EAS: `npx eas-cli@latest build --profile production`.

## Adding meal plans

1. Open `templates/MealPlan_Template.xlsx`. Regenerate it after the food DB changes with `python3 templates/build_template.py`.
2. Fill in Plans, Meals and Ingredients. Reference foods by `food_id` from the Foods sheet, or by name (the importer fuzzy-matches names and flags anything uncertain). **Never type nutrition values.** They're computed from the cited food database.
3. In the app, go to You, then Plan admin, then upload. The report shows unmatched foods and days outside the calorie band. Publish (Supabase) or save on the device (demo mode).

## Backend

See `supabase/README.md`. Copy `.env.example` to `.env.local` and set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY`. Without them the app runs in offline demo mode.

## Food database

See `pipeline/README.md`. Run `python3 pipeline/run.py --inspect --input <file.xlsx>` first, then fill in the source mappings and run the full pipeline. It writes `pipeline/out/foods.json` (copy it to `src/data/foods.json`), a Supabase seed CSV, and a cleanup report.

*Nutrition targets: US/Canadian Dietary Reference Intakes (National Academies). Educational information, not medical advice.*
